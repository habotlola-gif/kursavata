# Обучение нейро-ротации

1. Включи модуль AimRecorder, подерись своей мышкой (лучше 20–30+ минут, разные соперники, земля и воздух), выключи.
   Файлы: `config/hatek/aim_data/aim_*.csv`.
2. `python train2.py aim_model.json aim_*.csv` (нужен только numpy). Это модель v2: 22 входа, 2×96 нейронов.
   `--v1` обучает старую модель на 14 входах (для сравнения), `train.py` — старый скрипт.
3. Положи `aim_model.json` в `config/hatek/` — режим Neural Rotation подхватит его вместо встроенного.
   Клиент сам понимает и v1 (14 входов), и v2 (22 входа).
